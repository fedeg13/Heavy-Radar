# Album Radar - Metal Edition 🤘
Proyecto para el Trabajo Práctico Final (Opción B) - UTN.

## Descripción
Aplicación web en React que consume la API de Last.fm para listar los álbumes más populares de Metal.

## Pasos para ejecutar localmente
1. Clonar el repositorio: `git clone <URL_DE_TU_REPO>`
2. Instalar dependencias: `npm install`
3. Iniciar entorno de desarrollo: `npm run dev`
